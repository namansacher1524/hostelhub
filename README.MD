# DormPulse 🏠

DormPulse is a modern Hostel Complaint Management System built using:

- Python (Flask)
- HTML
- CSS
- JavaScript

This project allows students to register hostel complaints and track them through a clean web interface.

---

# Features

✅ Register Complaints  
✅ View All Complaints  
✅ Search Complaint by ID  
✅ Resolve Complaints  
✅ Modern Responsive UI  
✅ Flask Backend + Frontend on Same Server  
✅ Real-Time Complaint Updates

# Installation Guide

## Step 1: Clone or Download Project

Download the project folder and open it in VS Code.

---

## Step 2: Install Flask

Open terminal inside project folder and run:

```bash
pip install flask
```

---

## Step 3: Run the Application

```bash
python app.py
```

---

## Step 4: Open in Browser

```bash
http://127.0.0.1:5000
```

The frontend will automatically load from the Flask backend server.

---

# Application Functions

## 1. Register Complaint

Students can:
- Enter name
- Enter room number
- Describe issue

A unique complaint ID is generated automatically.

---

## 2. View Complaints

Displays:
- Complaint ID
- Student Name
- Room Number
- Complaint Issue
- Status

---

## 3. Search Complaint

Search any complaint using complaint ID.

---

## 4. Resolve Complaint

Mark complaints as resolved.
